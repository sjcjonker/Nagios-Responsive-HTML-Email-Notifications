# Upstream relationship

The original project is:

- Author: Heini Holm Andersen

This repository is not presented as the original project or an official
successor. It is a separately written Python 3 implementation inspired by the
original responsive notification design. No license was present in the
upstream repository when this implementation was prepared, so the original PHP
source is intentionally not copied here and no license claim is made over it.

thank him for the original work, explain the relationship, and invite a license
